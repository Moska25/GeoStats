1 The problem

Official statistics are published, revised, corrected and reclassified. A platform that overwrites yesterday's file is lying to its users: it can no longer say what it knew, when it knew it, or whether a number moved.

The Georgian earnings series makes the second half of the problem concrete. Its annual workbook puts 1992, 1993, 1994 and 1995 in adjacent columns, and a footnote at the bottom of the sheet explains that those columns are denominated in Roubles, Coupons, Thousand Coupons and Lari. Read the row as one series and 1995 looks like a 99.8% collapse in wages. It was a redenomination. Nothing about the individual numbers is wrong; only reading them as one series is.

That shape of defect - every value plausible, the relationship between them meaningless - turns out to be the general case, and this platform is built around catching it:

  • Unit changes. Four currencies in one row of columns.
    • {% if primary_break %}
  • Definition changes. The labour force series breaks between {{ primary_break.before }} and {{ primary_break.after }} on the {{ primary_break.what }}: no unit moved, no year is missing, nothing is out of range, and the two halves count different people.
    • {% endif %}
  • Classification changes. Earnings by activity exist under NACE rev.1 and rev.2 with overlapping years and different category boundaries. They are kept apart and never spliced.
  • Spelling changes. Six workbooks spell Adjara four ways. Joining on the printed label would produce four regions where there is one.

Each retrieval is written to data/vintages/<dataset>/<UTC timestamp>/ holding the raw bytes, a meta.json with source URL, sha256, byte size and HTTP status, and the normalised rows. The files are chmod 0444 and the writer refuses a path that already exists. The sqlite database every page reads from is a derived index, rebuilt from those files on every start; if it ever disagrees with a vintage, the vintage wins.

Why the raw bytes and not just the parsed rows. A parser changes. When it does, the only way to know whether a number moved because Geostat revised it or because the parsing improved is to re-parse the original bytes. Keeping the rows alone would make those two causes indistinguishable forever.

A second source

One check does not read the vintage at all. Geostat publishes some series twice — as the spreadsheets this project ingests, and as tables in its PX-Web database — and SOURCE_AGREEMENT joins the two. They are reached by code paths that share nothing, so a parser that took the wrong column would pass every other check in the table above and fail this one immediately.

The API reading is frozen to disk with its own checksum, exactly as a spreadsheet retrieval is, so the comparison runs offline and the test suite stays deterministic. The tolerance is half the last digit PX-Web publishes: it rounds to one decimal place and the spreadsheets carry full precision, so anything larger is a real difference between the two publications rather than an artefact of rounding.

6 The analyst, and what it refuses

no LLM

The analyst is a regex intent router over a closed set of approved metric functions. That is a deliberate downgrade in flexibility for a large upgrade in checkability: every answer names the function and formula that produced it, and anything outside the set gets no answer rather than a plausible one.

7 Tests and accessibility

  • Parser behaviour pinned against the committed workbooks: confirmed published values, gap markers preserved rather than zeroed, a decimal comma refused rather than guessed.
  • Every contract passes on clean data and fails on the fault that targets it, naming the offending rows.
  • Region aliases, geography levels, quarterly parsing and quarter gaps, unit bounds, published identities, and composite-key uniqueness.
  • Batch refresh with one failing source, an empty body, unchanged bytes, and an unexpected exception — none of which may cancel the rest.
  • Vintage immutability: fault injection cannot change a committed vintage's checksum, and committed files are read-only on disk.
  • Every route returns 200 in both languages and carries its caveats; every page holds scrollWidth === clientWidth at 375px.

Deliberately not covered: the live network path (adapters' download is monkeypatched so the suite runs offline and deterministically), browser rendering, and the exact SVG geometry of the charts.

8 A five-minute demo

  1. Overview — the five figures, then the trap: the same published columns plotted naively and honestly side by side.
  2. Work — real pay against unemployment on separate axes, and the 2009/2010 definition break that no value check can see.
  3. Atlas — six workbooks joined on one region registry, as a cartogram rather than a map.
  4. Reliability — three genuine releases of one series, each with its own checksum, and the diff between them.
  5. Lab — break the currency era on a copy and watch the contract catch it, with the original's checksum proving it never moved.
  6. Ask — skip to the refusals. They are the interesting ones.
