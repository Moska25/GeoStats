The nominal-to-real breakdown

equivalent = amount × (CPI_{{ year_to }} / CPI_{{ year_from }}) = {{ '%.2f'|format(amount) }} × ({{ '%.4f'|format(cpi_hi) }} / {{ '%.4f'|format(cpi_lo) }}) = {{ '%.2f'|format(equivalent) }} GEL real = amount × (CPI_{{ year_from }} / CPI_{{ year_to }}) = {{ '%.2f'|format(amount) }} × ({{ '%.4f'|format(cpi_lo) }} / {{ '%.4f'|format(cpi_hi) }}) = {{ '%.2f'|format(real_today) }} GEL in {{ year_from }} prices

These two are inverses. Deflating {{ year_to }} money into {{ year_from }} prices and inflating {{ year_from }} money into {{ year_to }} prices use the same ratio the other way up; the test suite asserts the round trip returns the original amount.

Read this carefully. Both published figures are gross, before personal income tax, and the mean is an average over paid employees, not a typical salary. Being above the mean does not mean being paid more than most people: the mean sits well above the median because high earners pull it up. GeoStats will not convert either figure to take-home pay, because that needs the tax rules for each year and this project ingests statistics, not tax law.
